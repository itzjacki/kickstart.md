# Agents Catalog

This directory will contain agent configuration templates once the Kiro agent config format is confirmed. For now, no agent templates are bundled.

> **Note:** This catalog is still growing. Continue with the kickstart process as usual — it works fine without agent templates.

## Adding a new agent

1. Create a file: `templates/agents/[agent-name].json`
2. Follow the Kiro agent configuration format
3. Add an entry to this catalog with: description, inclusion criteria, and customization notes
